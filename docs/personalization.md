# 个性化、主页、音乐与联机

## 主题与背景

进入“设置”，可以切换 dark、light、auto 主题，并配置更新、下载和外观相关选项。

## 更新

“更新与外观”区域可以配置更新清单 URL，并手动检查、下载和应用 McGo 更新。下载阶段会校验清单中的大小、SHA256 和 Windows 可执行文件头；只有打包后的 `McGo.exe` 支持自动替换，开发运行模式会保留下载文件路径供手动处理。

勾选“启动时自动检查更新”后，McGo 启动时会静默检查；仅在发现可用更新时更新状态栏和结果框。

## 自定义主页

进入“设置”的“自定义主页”区域，可以填写本地 `.txt` / `.md` 文件路径，或点击“选择主页文件”。点击“刷新主页”后内容会显示在首页的“自定义主页”区域。

如需使用 `http(s)` 纯文本地址，必须勾选“允许联网主页纯文本”。联网内容只按纯文本展示，不执行脚本。

## 背景音乐

进入“设置”的“背景音乐”区域：

- 选择本地音频文件。
- 设置音量。
- 勾选“启用背景音乐”后点击“播放/应用”。
- 可设置游戏启动后自动暂停音乐。

## 页面隐藏

旧版支持隐藏下载页或管理页。当前 C# WinUI 3 版使用「主导航 + 底部导航」的固定结构：
首页/启动/下载/资源/整合包/联机在主区，账号/设置/日志/关于在底部。
设置里的“显示下载页”控制下载入口是否可见；`show_manage` 仅为兼容旧配置保留，不再生效。

## 联机入口

联机已独立为主导航页面。进入“联机”可以维护常用服务器地址、检测当前 NAT 类型，并启动 McGo P2P 隧道。

服务器列表每行一个地址，例如：

```text
mc.example.com:25565 | 生存服
play.example.net | 小游戏
```

点击“复制首个服务器”会复制第一行 `|` 前的地址。

NAT 检测使用 STUN 探测 UDP 公网映射；如果结果显示对称 NAT、地址相关映射或多出口 NAT，建议优先使用中继联机。

同一页面也提供 McGo P2P 隧道。默认中继为 `flyliq.cn:10721`，房主填写 Minecraft 局域网端口并启动“作为房主”，加入者填写同一个房间后启动“作为加入者”，再在 Minecraft 中连接 `127.0.0.1:本地监听端口`。服务端部署见 [P2P 联机与中继部署](p2p.md)。
