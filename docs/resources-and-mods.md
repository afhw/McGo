# 资源市场与 Mod 管理

## 资源市场

进入“资源”页面：

1. 选择资源类型：`mod`、`resourcepack` 或 `shader`。
2. 填写 Minecraft 版本和加载器，例如 `1.20.1` / `fabric`。
3. 输入关键词并搜索。
4. 选择结果后点击“安装选中资源”。

Modrinth 支持兼容性验证和一键安装必需依赖。安装选中资源时默认勾选“安装必需依赖”，会递归下载该资源声明的 required 前置。安装完成后，本地资源列表会刷新到目标版本对应的资源目录。

## 本地资源

右侧“本地资源”会扫描当前资源类型对应的目录，并显示文件名、启用/禁用状态、大小和相对路径。

- “刷新本地”会重新扫描当前版本运行目录。
- “查看详情”会显示路径、大小、修改时间、SHA1 和基础依赖提示。
- “启用/禁用”会切换 `.disabled` 后缀。
- “删除”会删除选中的本地资源文件。

## 依赖检查

“解析依赖”会扫描 Mods 目录中已启用的 `.jar`，通过 Modrinth 文件 hash 识别项目并列出缺失的 required 前置。“安装缺失前置”会按当前 Minecraft 版本和加载器自动补齐。
