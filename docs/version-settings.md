# 版本设置与启动参数

进入“启动”页面，选择本地版本后在“启动参数”区域管理当前版本。

## 本地版本

本地版本列表会显示当前游戏目录中可用的版本。分类框支持“全部版本”“收藏”“原版”“仅 OptiFine”“可安装 Mod”和“隐藏”。收藏版本会优先排序；隐藏版本只会出现在“隐藏”分类中。

选择版本后，可以设置别名、收藏、隐藏、Quick Play 世界、最大内存、GC 策略和版本独立目录。

## 启动设置

- Java 路径：默认 `java`，也可以填写本机 Java 可执行文件路径。
- 检测 Java：读取当前路径的 Java 主版本，并和所选 Minecraft 版本需求对比。
- 下载推荐 Java：按所选版本需要的 Java 主版本下载 Eclipse Temurin JRE，解压到当前游戏目录的 `java_runtimes`，并自动写回 Java 路径。
- 别名：给当前版本起显示名称。
- Quick Play 世界：填写存档文件夹名，启动后直接进入该单人存档。
- 最大内存 MB / 最小内存 MB：分别写入 `-Xmx` 和 `-Xms`。
- 窗口宽度 / 高度：设置 Minecraft 启动分辨率。
- GC 策略：高级模式下显示，支持 G1GC、ZGC、Shenandoah 或默认。
- 额外 JVM 参数：追加到 Java 参数中。
- 额外游戏参数：追加到 Minecraft 游戏参数中。
- 启动前命令：启动游戏进程前在当前运行目录执行；命令失败会中止启动。
- 自定义运行目录：覆盖默认 `.minecraft` 或版本独立目录。
- 自定义 Mods 目录：覆盖资源管理和快捷入口使用的 mods 目录。
- 资源隔离：让当前版本使用 `versions/<版本名>/` 作为运行目录。

点击“启动游戏”前，启动器会检查 Java 版本是否满足当前 Minecraft、版本清单继承链是否存在、客户端/依赖库/assets 是否缺失或校验失败，以及 natives 是否已经解压。检查失败时会在启动参数输出框显示原因，可先执行“补全/校验文件”修复。

## 快捷入口

启动页提供当前版本的快捷入口：

- 版本文件夹：打开 `versions/<版本ID>`。
- 存档、Mods、资源包、光影、截图：打开当前运行目录下的对应文件夹；启用版本独立目录时会指向 `versions/<版本ID>/`。
- 导出启动脚本：把当前账号、Java、内存、外置登录和版本参数导出为 `mcgo_scripts/launch-<版本ID>.bat`。
- 删除版本：确认后删除当前 `versions/<版本ID>` 目录，并清理对应版本设置。

整合包导入导出、崩溃分析和资源管理已迁移到独立的“整合包”和“资源”页面。
