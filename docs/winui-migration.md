# WinUI 3 功能迁移清单

目标：WinUI 3 客户端必须承接旧版启动器能力；WPF 临时壳只能作为迁移参照，不能作为最终交付。

## 已迁移到 WinUI 3

- [x] 主窗口与导航：首页、启动、下载、账号、资源、整合包、联机、设置、日志、关于。
- [x] 首页状态：本地版本数、账号数、推荐内存、当前游戏目录。
- [x] 启动页基础：本地版本扫描。
- [x] 账号页基础：账号列表读取。
- [x] 设置页基础：游戏目录、Java 路径、更新清单、自动检查更新、保存设置、检查更新。
- [x] 设置页增强：下载镜像/缓存/并发/限速、Modrinth API/CDN 代理、WinUI 文件/目录选择器。
- [x] 个性化：主题、背景图、自定义主页、本地/联网纯文本主页、背景音乐、启动游戏后暂停音乐。
- [x] 更新完整闭环：检查更新、下载更新、应用更新、开发/非打包模式提示、打包 exe 自动替换。
- [x] 日志页基础：读取最新日志。
- [x] 下载页核心：远程版本刷新、游戏下载、assets 开关、Fabric/Forge/NeoForge/Fabric API/OptiFine 安装选项。
- [x] 下载任务中心：任务队列、当前任务、失败重试、取消、进度/速度/复用统计。
- [x] 联机页核心：服务器列表、复制首个服务器、NAT 检测、P2P 设置保存、邀请信息、房主/加入者隧道、停止隧道。
- [x] 启动页主路径：账号选择、版本分类、版本独立设置、启动前命令、GC 策略、窗口大小、Quick Play、启动前检查、生成命令、启动游戏、修复文件、导出启动脚本、删除版本、打开版本相关目录。
- [x] Java 管理主路径：检测 Java、按版本下载推荐 Java、自动写入 Java 路径。
- [x] 账号管理主路径：添加/更新/删除离线账号、Microsoft 登录链接/回调、外置登录、authlib-injector 自动下载、认证服务器探测、生成 JVM 参数。
- [x] 账号增强：authlib-injector 本地文件选择器、已登录账号手动刷新、Microsoft 登录自动打开/复制链接/外部浏览器提示。
- [x] 资源市场主路径：Modrinth 搜索、安装选中资源、必需依赖递归安装、本地资源刷新/详情/启用/禁用/删除、缺失前置解析与修复。
- [x] 资源增强：结果版本详情/截图缓存队列、兼容性后台标记、资源来源和排序筛选。
- [x] 整合包与胶囊主路径：Modrinth/CurseForge/plain zip 导入导出、开黑胶囊导入导出、P2P 信息写入/读取、缺失文件报告、崩溃日志分析。

## 已完成的收口项

- [x] 整合包增强：WinUI 文件选择器、胶囊联机文件 host/pull、导入冲突更细提示。
- [x] 联机增强：P2P 运行状态可视化、剪贴板邀请、胶囊文件 host/pull、异常恢复提示。
- [x] UI 冒烟测试：WinUI 3 发布版启动、主要导航可达、关键按钮不会启动即崩。

完成标准：上面所有待办都迁移到 WinUI 3，`dotnet build McGo.slnx`、核心测试、发布脚本和发布版启动验证全部通过。
