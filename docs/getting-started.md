# 快速开始与界面概览

## 安装依赖

```bash
dotnet --info
```

## 启动

```bash
dotnet run --project src/McGo.WinUI/McGo.WinUI.csproj
```

首次启动后建议按这个顺序操作：

1. 进入“账号”，添加离线、Microsoft 或外置登录账号。
2. 进入“启动”或“设置”，确认游戏目录和 Java 路径。没有合适 Java 时，可在“启动”页选择版本后点击“下载推荐 Java”。
3. 进入“下载”，刷新远程版本并下载 Minecraft。
4. 回到“启动”，选择账号和本地版本后启动游戏。

## 页面说明

- 首页：显示账号、Java、本地版本、远程版本和自定义主页内容。
- 启动：选择账号、版本、版本分类，并管理当前版本设置。
- 下载：下载原版、串联 Fabric/OptiFine/Fabric API 安装任务。
- 账号：管理离线、Microsoft 和外置登录账号。
- 资源：搜索 Modrinth 资源、检查本地 Mod 依赖。
- 整合包：导出 Modrinth/CurseForge 包、分析崩溃日志。
- 联机：配置中继、房间号、UDP 优先联机和邀请信息。
- 设置/日志：下载、更新、外观和诊断入口。
