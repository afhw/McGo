# 快速开始与界面概览

## 安装依赖

```bash
dotnet --info
```

## 启动

```bash
dotnet run --project src/McGo.WinUI/McGo.WinUI.csproj
```

## 三步开游戏

界面按“缺什么就提示什么”设计，主按钮会一直指向当前最该做的那一步：

1. **账号** — 点“添加离线账号”，填一个用户名即可。之后可随时换成 Microsoft 或外置登录。
2. **下载** — 选一个原版版本，需要 Mod 就顺手选加载器，然后下载。
3. **启动** — 回到“启动”页，账号、版本、Java 三项都变成强调色后点“启动游戏”。

“启动”页顶部有三个检查项（账号 / 版本 / Java）。哪一项还是灰色，就说明还差什么；
下方的说明文字会直接告诉你下一步该点哪里。

## 页面说明

主导航（左侧）：

- **首页**：一眼看到当前能否开游戏；主按钮按缺口自动切换为“先添加账号 / 去下载版本 / 进入启动页”。
- **启动**：选账号与版本、查看启动前检查清单、配置版本独立设置（内存、GC、参数、Mod）。
- **下载**：下载原版并串联 Fabric/Forge/NeoForge/OptiFine 安装，任务统一排队。
- **资源**：搜索 Modrinth 的 Mod、资源包、光影、数据包，或管理本地资源。
- **整合包**：导入/导出整合包、开黑胶囊与崩溃日志分析。
- **联机**：P2P 隧道、NAT 检测、常用服务器与开黑胶囊同步。

底部导航：

- **账号**：管理离线、Microsoft 和外置登录账号。没有任何账号时会显示一键添加入口。
- **设置**：游戏目录、Java、下载参数、主题与功能、背景音乐、更新。
- **日志**：读取 McGo 与 Minecraft 的运行日志。
- **关于**：目录说明与致谢。

## 布局约定

- 宽窗口（≥ 900px）左右分栏：主操作在左，状态与辅助信息在右；窄窗口自动堆叠为单列。
- 所有页面使用统一的卡片、标题、检查项样式，主要操作使用强调色，其余为次级按钮。
